# L1.5-TASK-002 临时邮箱工具站 UI 规格

## 1. 设计Token

### 1.1 色彩系统

| Token | 亮色模式 | 暗色模式 | 用途 |
|-------|----------|----------|------|
| `--color-primary` | `#1677ff` | `#1668dc` | 主操作按钮、链接、选中态 |
| `--color-primary-hover` | `#4096ff` | `#3c89e8` | 主色悬停 |
| `--color-success` | `#52c41a` | `#49aa19` | 复制成功、邮件到达提示 |
| `--color-warning` | `#faad14` | `#d89614` | 即将过期提示 |
| `--color-error` | `#ff4d4f` | `#dc4446` | 错误状态、删除操作 |
| `--color-bg-layout` | `#f5f5f5` | `#141414` | 页面背景 |
| `--color-bg-container` | `#ffffff` | `#1f1f1f` | 卡片/容器背景 |
| `--color-bg-elevated` | `#ffffff` | `#2a2a2a` | 弹层/下拉背景 |
| `--color-text-primary` | `rgba(0,0,0,0.88)` | `rgba(255,255,255,0.85)` | 标题、正文 |
| `--color-text-secondary` | `rgba(0,0,0,0.65)` | `rgba(255,255,255,0.65)` | 辅助文字 |
| `--color-text-tertiary` | `rgba(0,0,0,0.45)` | `rgba(255,255,255,0.45)` | 占位符、禁用文字 |
| `--color-border` | `#d9d9d9` | `#424242` | 边框、分割线 |

### 1.2 字体

| 场景 | 字体栈 |
|------|--------|
| 中文正文 | `"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif` |
| 英文正文 | `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif` |
| 邮箱地址/代码 | `"SF Mono", "JetBrains Mono", "Fira Code", monospace` |

| 层级 | 字号 | 行高 | 字重 |
|------|------|------|------|
| H1 页面标题 | 30px | 38px | 600 |
| H2 区块标题 | 24px | 32px | 600 |
| H3 卡片标题 | 20px | 28px | 500 |
| Body 正文 | 14px | 22px | 400 |
| Caption 辅助 | 12px | 20px | 400 |
| 邮箱地址 | 20px | 28px | 500 |

### 1.3 间距系统（4px 基准）

| Token | 值 | 用途 |
|-------|-----|------|
| `--spacing-xs` | 4px | 图标与文字间距 |
| `--spacing-sm` | 8px | 紧凑元素间距 |
| `--spacing-md` | 16px | 常规元素间距 |
| `--spacing-lg` | 24px | 区块间距 |
| `--spacing-xl` | 32px | 大区块间距 |
| `--spacing-xxl` | 48px | 页面级间距 |

### 1.4 圆角与阴影

| Token | 值 |
|-------|-----|
| `--radius-sm` | 4px |
| `--radius-md` | 8px |
| `--radius-lg` | 12px |
| `--shadow-sm` | `0 1px 2px rgba(0,0,0,0.06)` |
| `--shadow-md` | `0 4px 12px rgba(0,0,0,0.08)` |
| `--shadow-lg` | `0 8px 24px rgba(0,0,0,0.12)` |

### 1.5 响应式断点

| 名称 | 范围 | 布局策略 |
|------|------|----------|
| Mobile | < 768px | 单列，侧边栏隐藏，广告位堆叠 |
| Tablet | 768px - 1024px | 双列，侧边栏收窄 |
| Desktop | > 1024px | 三列（内容+侧边栏），最大宽度 1200px |

## 4. 全局组件规格

### 4.1 AppHeader

| 属性 | 规格 |
|------|------|
| 高度 | Desktop: 64px, Mobile: 56px |
| 背景 | `--color-bg-container` + `--shadow-sm` |
| 定位 | `position: sticky; top: 0; z-index: 100` |
| 内容 | Logo(左) + 导航链接(中, Desktop) + 语言/主题切换(右) |
| Mobile | Logo居中, 汉堡菜单(左), 语言切换(右) |

| 交互 | 触发 | 响应 |
|------|------|------|
| 点击Logo | click | 路由到 `/` |
| 语言切换 | click dropdown item | 切换 locale store, URL 不变, 页面文案刷新 |
| 主题切换 | click switch | 切换 `document.documentElement.dataset.theme`, 持久化到 localStorage |

### 4.2 AdSlot

| Props | 类型 | 说明 |
|-------|------|------|
| `slot` | string | 广告位ID |
| `fallback` | boolean | 无广告时是否显示占位 (默认true) |

| 状态 | 展示 |
|------|------|
| 加载中 | 灰色骨架屏，尺寸与广告位一致 |
| 已加载 | 渲染广告内容 |
| 无广告 | `fallback=true` 时显示浅色占位框 + "AD" 文字; `false` 时隐藏 |

### 4.3 LanguageSwitcher

| 规格 | 说明 |
|------|------|
| 组件 | `a-dropdown` + `a-button` |
| 选项 | 🇨🇳 中文 / 🇺🇸 English |
| 数据来源 | `locale` store |
| 文案适配 | 切换后所有 `$t()` 文案即时更新，按钮宽度需适配最长文案 |

### 4.4 ThemeSwitcher

| 规格 | 说明 |
|------|------|
| 组件 | `a-switch` + 太阳/月亮图标 |
| 数据来源 | localStorage `theme` 键 |
| 默认值 | 跟随系统 `prefers-color-scheme` |

#### 5.1.1 MailboxGenerator 组件

**布局：**
```
┌─────────────────────────────────────────────────┐
│  "您的临时邮箱地址"  (标题, H2)                    │
├─────────────────────────────────────────────────┤

│ │  abc123xyz@tempmail.dev          [📋] [🔄]  │ │

│        ↑ 邮箱地址 (monospace, 20px)              │

└─────────────────────────────────────────────────┘
```

**组件列表：**

| 组件/元素 | Ant Design组件 | 数据来源 | 说明 |
|-----------|---------------|----------|------|
| 邮箱地址显示 | `a-typography-text` + `copyable` | `mailbox` store → `address` | monospace字体, 可选中 |
| 复制按钮 | `a-button` type=primary | — | 调用 `navigator.clipboard.writeText()` |
| 刷新按钮 | `a-button` | — | 调用 `POST /api/mailbox` 生成新邮箱 |
| 域名选择器 | `a-select` | `mailbox` store → `domains[]` | 可选，默认随机域名 |
| 过期倒计时 | `a-statistic-countdown` | `mailbox` store → `expiresAt` | 格式 mm:ss |

**交互行为：**

| 用户操作 | 触发事件 | 页面响应 |
|----------|----------|----------|
| 首次进入页面 | `onMounted` | 自动调用 `POST /api/mailbox` 生成邮箱，建立 WebSocket 连接 |
| 点击复制 | click | 复制地址到剪贴板，按钮变为 ✓ 持续2秒，`a-message.success("已复制")` |
| 点击刷新 | click | 断开旧 WS，调用 `POST /api/mailbox`，更新地址，建立新 WS |
| 切换域名 | change | 同刷新逻辑，使用选定域名调用 API |
| 倒计时归零 | countdown finish | 显示 `a-alert` 提示过期，自动生成新邮箱 |

**状态覆盖：**

| 状态 | 展示 |
|------|------|
| 加载中 | 邮箱地址区域显示 `a-skeleton` 骨架屏 (1行, 宽度60%) |
| 正常 | 显示完整邮箱地址 + 操作按钮 + 倒计时 |
| 错误 | `a-alert` type=error: "生成邮箱失败，请刷新重试" + 重试按钮 |
| 已过期 | 地址置灰 + `a-tag` color=orange "已过期" + 自动刷新 |

| 邮件头信息 | `a-descriptions` | `EmailDetail` | 发件人/收件人/时间 |
| 邮件正文 | `div` + `v-html` | `EmailDetail.htmlBody` | DOMPurify 净化后渲染 |
| 纯文本回退 | `pre` | `EmailDetail.textBody` | 无HTML时显示纯文本 |
| 附件列表 | `a-card` grid | `EmailDetail.attachments[]` | 卡片网格布局 |
| 下载按钮 | `a-button` size=small | `attachment.downloadUrl` | 触发浏览器下载 |

**交互行为：**

| 用户操作 | 触发事件 | 页面响应 |
|----------|----------|----------|
| 进入页面 | `onMounted` | 调用 `GET /api/mailbox/{token}/emails/{emailId}` |
| 点击返回 | click | `router.back()` 或路由到 `/` |
| 点击删除 | click | `a-modal.confirm` 二次确认 → `DELETE` API → 返回收件箱 |
| 点击下载附件 | click | 触发 `<a download>` 下载文件流 |
| 邮件内链接 | click | `target="_blank" rel="noopener"` 新窗口打开 |

**状态覆盖：**

| 状态 | 展示 |
|------|------|
| 加载中 | `a-skeleton` 段落骨架 (标题1行 + 正文4行) |
| 正常 | 完整邮件头 + 正文 + 附件 |
| 错误(404) | `a-result` status=404 "邮件不存在" + 返回按钮 |
| 错误(410) | `a-result` status=warning "邮箱已过期" + 生成新邮箱按钮 |
| 错误(网络) | `a-result` status=error "加载失败" + 重试按钮 |

**API 调用：**

| API | 触发时机 | 用途 |
|-----|----------|------|
| `GET /api/mailbox/{token}/emails/{emailId}` | 页面加载 | 获取邮件详情 |
| `GET /api/mailbox/{token}/emails/{emailId}/attachments/{filename}` | 点击下载 | 下载附件 |
| `DELETE /api/mailbox/{token}` | 点击删除确认 | 删除邮箱(含所有邮件) |

## 6. API 对接汇总

| API | 方法 | 触发页面/组件 | 触发时机 | 用途 |
|-----|------|--------------|----------|------|
| `/api/mailbox` | POST | MailboxGenerator | 首次加载/刷新/切换域名 | 生成临时邮箱 |
| `/api/mailbox/{token}` | GET | HomeView | 页面恢复(localStorage有token时) | 检查邮箱是否有效 |
| `/api/mailbox/{token}` | DELETE | EmailDetailView | 用户确认删除 | 删除邮箱及邮件 |
| `/api/mailbox/{token}/emails` | GET | InboxList | 首次加载/下拉刷新/翻页 | 获取邮件列表 |
| `/api/mailbox/{token}/emails/{id}` | GET | EmailDetailView | 页面加载 | 获取邮件详情 |
| `/api/mailbox/{token}/emails/{id}/attachments/{file}` | GET | AttachmentList | 点击下载 | 下载附件 |
| `/api/seo/landing/{slug}` | GET | LandingView | 页面加载 | 落地页数据 |
| `ws://host/ws/{token}` | WebSocket | InboxList | 邮箱生成后 | 实时接收新邮件 |
